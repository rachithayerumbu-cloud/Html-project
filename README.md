# 📚 Library Management System

A simple and interactive **Library Management System** built using **HTML, CSS. This web-based application allows users to log in, search for books, add new books, and remove books from the library collection through an easy-to-use interface.

## 🚀 Features

### 🔐 User Login

* Provides a login interface for authorized access.
* Validates the entered username and password.
* Shows an appropriate error message when incorrect credentials are provided.

### 🏠 Home

* Introduces users to the Library Management System.
* Provides a simple and welcoming starting page.

### ℹ️ About Us

* Provides details about the library and its available collection.
* Helps users understand the purpose of the system.

### 🔍 Search / Find Books

* Allows users to search for books using the book title.
* Displays important book information, including:

  * 📖 Book Title
  * ✍️ Author
  * 📂 Category
  * 📅 Publication Year
  * 📍 Library Location

### ➕ Add New Book

* Enables users to add books to the library collection.
* Users can enter:

  * Book title
  * Author name
  * Category
  * Publication year
  * Library location

### 🗑️ Delete Book

* Allows users to remove an existing book from the collection.
* Books can be identified and deleted using their title.

### 🎨 User Interface

* Features a clean and professional blue-themed design.
* Provides simple navigation between different sections.
* Designed to offer a user-friendly browsing experience.

## 🛠️ Technologies Used

## 🎯 Project Objective

The main goal of this project is to develop a basic web-based library application that demonstrates essential library operations. It provides users with a convenient way to search, add, and delete books while showcasing the practical use of **HTML, CSS, and JavaScript** in web development.
